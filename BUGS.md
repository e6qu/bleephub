# Bleephub bug ledger

994 findings from the continuing full-surface audit: 183 blockers, 490 major, 321 minor. Every
entry carries a location and a one-sentence claim. Severity is `B` blocker, `M` major, `m` minor.
Status begins with one of `open`, `partial`, `fixed`, `deferred`, or `false-positive`; the
generated parity inventory records the exact counts and fails CI when this summary or a row
drifts. `deferred` is work deliberately not done yet but that should eventually be done;
`false-positive` is a finding whose premise is wrong, so the proposed fix should never be done.

IDs are for this ledger only — per project convention they never appear in
source or comments. The reasoning behind a fix belongs in its commit message.
