# Vendored emoji asset provenance

Provenance for the two vendored emoji artifacts embedded by the server
(`gh_emoji_assets.go` embeds `emoji_assets.tar.gz`; `gh_meta_extras.go` embeds
`gemoji_catalog.txt`). Each record fixes the upstream source, the upstream
revision/version, and a SHA-256 of the exact bytes committed here. The SHA-256
values were computed locally with `shasum -a 256 <file>` and match the digests
also recorded in `THIRD-PARTY-NOTICES.md`.

Do not edit the binary/text assets in place. `emoji_assets.tar.gz` is
regenerated by `go generate ./internal/emojigen`, which re-pins its own source
commit and tarball digest.
