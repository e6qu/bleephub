# Third-party notices

Bleephub vendors and redistributes the following third-party material. Anything
that ships inside a published container image is marked as such, because that is
where redistribution obligations attach.

## Twemoji — CC-BY 4.0 — **redistributed in the server image**

Emoji raster images backing `GET /emojis` and `/images/icons/emoji/`.

| | |
|---|---|
| Upstream | https://github.com/jdecked/twemoji |
| Version | v17.0.3 |
| Vendored as | `internal/server/emoji_assets.tar.gz` |
| Generated by | `go generate ./internal/emojigen` |
| Licence | Creative Commons Attribution 4.0 International (CC-BY 4.0) |

Attribution and the licence text ride inside the generated archive as
`ATTRIBUTION` and `LICENSE-TWEMOJI`.

**Provenance gap:** the generator resolves the upstream tarball by git *tag*,
which is mutable, and verifies no checksum. Until that is pinned to a commit
with a recorded SHA-256, the vendored bytes cannot be independently verified.
Tracked as `CORE-026`.

## gemoji — MIT — **redistributed in the server image**

The emoji name catalogue backing the same endpoints.

| | |
|---|---|
| Upstream | https://github.com/github/gemoji |
| Vendored as | `internal/server/gemoji_catalog.txt` |
| Licence | MIT |

**Provenance gap:** no source URL, upstream commit or checksum is recorded
alongside the file. Tracked as `CI-032`.

## GitHub OpenAPI description — MIT — test fixture only

Used by the route and response-shape fidelity gates. Not shipped.

| | |
|---|---|
| Upstream | https://github.com/github/rest-api-description |
| Vendored as | `internal/server/testdata/github-openapi.json.gz` |
| Refreshed by | `scripts/update-github-openapi.sh` |
| Licence | MIT |

**Provenance gap:** fetched from the `main` branch tip with no commit pin, date
or checksum recorded. Tracked as `PAR-005`.

## GitHub Actions runner — MIT — **redistributed in the runner image**

The official runner binary, downloaded during the build of
`ghcr.io/e6qu/bleephub-runner`.

| | |
|---|---|
| Upstream | https://github.com/actions/runner |
| Version | pinned by `RUNNER_VERSION` in `Dockerfile.runner` |
| Licence | MIT |

**Provenance gap:** the release tarball is piped from `curl` into `tar` with no
checksum verification. Tracked as `CI-011`.

## github-pages / Jekyll toolchain — MIT — **redistributed in the server image**

The `github-pages` gem (pinned to 232) and its transitive dependencies are
installed into the release image to run Pages builds.

**Provenance gap:** the `Gemfile` is generated inline in `Dockerfile.release`
with no committed `Gemfile.lock`, so the roughly ninety transitive gems float
between builds. Tracked as `CI-028`.

## Go module dependencies

Declared in `go.mod` and pinned by `go.sum`. `go mod download` plus
`go mod verify` reproduces and checks them.
